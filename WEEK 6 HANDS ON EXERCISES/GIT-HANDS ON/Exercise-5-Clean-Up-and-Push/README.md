# Exercise 5 – Clean Up & Push

## Objective

Pull the latest changes from the remote repository, commit new changes, and push them back.

## Commands Used

```bash
git status

git branch -a

git pull origin master

echo "Lab 1 changes" > lab1.txt

git add lab1.txt

git commit -m "Git-T03-HOL_002 changes"

git push origin master

git ls-remote origin
```

## Result

The repository was synchronized successfully with the remote repository.
